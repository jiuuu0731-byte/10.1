# 네오의 작은 세계

첨부 디자인을 참고한 연한 하늘색과 보라색의 스크롤형 홈페이지입니다. 아래로 스크롤하면 모든 내용이 한 페이지에서 이어집니다. 일정은 탭 전환 없이 전체 표시합니다. 별도 설치 없이 실행할 수 있습니다.

## 열기
`홈페이지 열기.cmd` 또는 `index.html`을 더블클릭하세요. HTML, CSS, JavaScript와 사진을 모두 포함하므로 인터넷 없이도 열립니다.

## 네오 정보 수정
- `content.js`: 프로필, 특징과 성격, 예시 하루 일정, 성장기와 생애 기록
- `index.html`: 기부 소개 문구, FAQ와 메인 소개
- `assets/neo.jpg`: 실제 네오 사진으로 교체 (이름을 그대로 유지)
- `style.css`: 색상과 디자인

사진은 가족이 제공한 네오의 실제 사진입니다. 생일(2023.08.31)은 공개 인스타그램 프로필과 가족의 정보로 확인했습니다. 성격은 가족의 표현인 “사람으로 치면 ISTP”를 사용했습니다. 부산지회 착한펫 월 2만 원 기부는 가족이 제공한 정보입니다. 착한펫 제도는 공식 안내를 확인했습니다. 품종은 가족이 알려준 노르웨이 숲고양이와 랙돌 믹스이며, 좋아하는 간식은 연어맛 츄르입니다. 성별, 첫 만남과 성장 날짜, 기부 시작일은 확인되지 않아 추측하지 않았습니다. 하루 일정은 여전히 예시이며 실제 생활 정보가 확인되면 수정해주세요. 나이는 서울 날짜 기준으로 자동 계산합니다. Instagram 게시물 본문은 로그인 제한으로 확인하지 못했습니다.

## GitHub 업로드 / GitHub Pages
1. GitHub에서 새 저장소를 만드세요.
2. 이 폴더 **안의 파일과 assets 폴더**를 저장소 루트에 업로드하세요. ZIP 파일 자체를 업로드하지 마세요.
3. 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save를 선택하세요.
4. 배포 완료 후 Pages에 표시된 주소를 여세요.

별도 빌드나 npm 설치가 필요하지 않습니다. GitHub 업로드 및 실제 배포는 수행하지 않았습니다.
